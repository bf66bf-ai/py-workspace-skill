# 示例：咨询顾问的工作区

这是一个为咨询顾问设计的工作区示例，展示如何使用 py-workspace skill。

## 背景

王老师是一位商业咨询顾问，主要业务：
- 为创业者提供商业模式诊断
- 开发和销售在线课程
- 偶尔接受企业培训邀约

## 初始化过程

### Step 1: 运行初始化命令

```bash
/py-workspace init
```

**结果**：
```
✅ 工作区初始化完成

创建了以下结构：
- SOURCE_OF_TRUTH.md
- AGENTS.md
- 工作记录/
  └── 2026-09-23.md
- 文件上传区/
- 文件下载区/
```

### Step 2: 准备资料

王老师将资料按习惯分类后放入上传区：

```
文件上传区/
├── 项目资料/
│   ├── 张三-商业诊断需求.docx
│   ├── 李四-课程定制合同.pdf

│   └── 第二章-逐字稿.md
```

还有一些未分类的：

### Step 3: 运行整理命令

```bash
/py-workspace organize
```

**对话过程**：

```

1. 文件上传区/项目资料/ (3个文件)
2. 文件上传区/参考资料/ (3个文件)
3. 文件上传区/创作素材/ (2个文件)

我会在根目录创建这三个文件夹并移动文件，可以吗？

👤 可以

🤖 好的。另外发现 2 个未分类文件：

1. 2026年产出数据.xlsx
   建议分类：数据报表
   理由：包含客户统计数据

2. 待整理笔记.md
   建议分类：个人笔记
   理由：看起来是临时记录

这样分类可以吗？你也可以修改文件夹名称。

✅ 文件整理完成：

```

### Step 4: 确认使用规则

```
🤖 资料已经就位，现在我们来确定几条使用规则：

1. **读取优先级**
   当我需要了解你的工作时，应该按什么顺序读取这些资料？
   
   我的建议：
   - 项目资料/ > 参考资料/ > 数据报表/ > 创作素材/ > 工作笔记/
   
   理由：项目资料是核心业务，课程是主要产品，其他是辅助资料。

🤖 2. **版本冲突处理**
   如果同一个主题在不同文件夹都有资料，以哪个为准？
   
   我的建议：
   - 文件修改时间越新，优先级越高
   - 明确标注"终稿"、"最终版"的优先于草稿
   
👤 同意

🤖 3. **引用确认**
   哪些资料我可以直接引用到回复或文档中？哪些需要先征得你的同意？
   
   我的建议：
   - 参考资料/ - 可以直接引用（这是你的知识产品）
   - 创作素材/ - 可以直接引用（公开内容）
   - 项目资料/ - 需要先确认（涉及客户隐私）
   - 数据报表/ - 需要先确认（敏感数据）
   - 工作笔记/ - 需要先确认（个人记录）

🤖 ✅ 规则已保存到 AGENTS.md
```


## 生成的 SOURCE_OF_TRUTH.md

```markdown
# 工作区导航

本文件告诉 Agent：资料在哪里、包含什么、优先使用哪个版本。

## 快速查找

| 要找什么 | 去哪里 | 当前状态／备注 |
|---|---|---|
| 客户需求、合同、咨询记录 | `项目资料/` | 3个文件 |
| 课程大纲、逐字稿 | `参考资料/` | 3个文件 |
| 文案、海报等营销内容 | `创作素材/` | 2个文件 |
| 产出数据统计 | `数据报表/` | 1个文件 |
| 个人临时笔记 | `工作笔记/` | 1个文件 |
| 每日工作进展 | `工作记录/` | 按日期记录 |
| 新增资料入口 | `文件上传区/` | 处理后会移走 |
| 对外交付备份 | `文件下载区/` | 可随时删除移动 |

## 目录职责

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `工作记录/` | 每日对话产出、阶段性成果、关键决定 | 完整业务材料、未验证的计划 |
| `文件上传区/` | 新增资料的临时入口 | 已分类资料（会被移走） |
| `文件下载区/` | 对外交付物备份 | 唯一的原始文件 |
| `项目资料/` | 客户需求、合同、咨询记录、诊断报告 | 营销内容、课程教学内容 |
| `参考资料/` | 课程大纲、逐字稿、教学素材 | 客户个人信息 |
| `创作素材/` | 朋友圈文案、招生海报、推广内容 | 客户隐私、合同 |
| `数据报表/` | 客户统计、业绩报表、数据分析 | 原始对话记录 |
| `工作笔记/` | 个人临时笔记、待整理想法 | 正式交付文档 |

## 读取优先级

当需要了解业务背景时，按以下顺序读取：
1. 项目资料/ (核心业务)
2. 参考资料/ (主要产品)
3. 数据报表/ (业务数据)
4. 创作素材/ (市场材料)
5. 工作笔记/ (辅助记录)

## 版本冲突规则

1. 文件修改时间越新，优先级越高
2. 明确标注"终稿"、"最终版"的优先于草稿
3. 无法判断时询问用户，不自行选择

## 引用规则

- **可直接引用**：参考资料/、创作素材/
- **需要确认**：项目资料/、数据报表/、工作笔记/（涉及隐私或敏感信息）
```

## 日常使用场景

### 场景 1：新项目资料

```
👤 我接了一个新项目，叫赵六，需要做商业模式诊断

🤖 好的。我读取了「项目资料/」的历史案例，看到你之前为张三和李四做过类似诊断。
   
   标准流程包括：
   1. 需求访谈
   2. 商业模式画布分析
   3. 诊断报告
   
   需要我为赵六创建项目文件夹吗？

👤 可以，先创建一个需求文档

🤖 [创建 项目资料/赵六-商业诊断需求.md]
   
   已创建。需要我把这个文档复制到「文件下载区/」方便你发出去吗？

👤 先不用，等我填完内容再说
```

### 场景 2：准备课程交付

```
👤 创业方法课的第三章逐字稿写完了，准备录制

   第三章逐字稿已保存在哪里？

👤 在「参考资料/第三章-逐字稿.md」

🤖 确认了。这是要交付的版本吗？需要我复制到「文件下载区/」备份吗？

👤 对，复制一份

🤖 ✅ 已复制到「文件下载区/第三章-逐字稿-录制版.md」
   
   已记录到今日工作日志：
   - 时间：14:30
   - 成果：创业方法课第三章逐字稿完成
   - 状态：准备录制
   - 备份：已复制到文件下载区
```

第二天，王老师在新窗口打开项目：



## 总结

通过 py-workspace skill，王老师：

1. ✅ **一次配置，长期受益**：只需初始化一次，后续新资料自动归档
2. ✅ **保持习惯**：Agent 保留了"项目资料"、"参考资料"等原有分类
3. ✅ **避免混乱**：文件从上传区移走，不留副本，单一来源
4. ✅ **跨窗口续接**：新窗口自动读取历史，无需重复解释
5. ✅ **安全备份**：交付物独立备份，不影响主工作区

王老师现在可以专注于业务本身，而不是花时间整理文件和向 Agent 解释"这个文件在哪"。
