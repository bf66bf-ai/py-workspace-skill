# Agent 工作规则

本文件定义 Agent 如何读取和使用工作区资料。

## 读取协议

- 处理业务任务前，先读取 `SOURCE_OF_TRUTH.md` 确定资料位置
- 需要了解业务背景时，按以下优先级读取：

- 引用涉及客户隐私的资料前，先确认是否可以使用
- 找不到资料时询问用户，不自行假设或编造内容

## 文件交接规则

- **文件上传区/**：新资料入口，处理后文件会被移走（move，不是 copy），不保留副本
- **文件下载区/**：客户交付物备份，可随时删除、移动、复制，不影响主工作区
- 用户确认要交付的成果时，主动询问是否需要复制到下载区

## 工作记录规则

- 每天自动创建当日工作记录文件（格式：`YYYY-MM-DD.md`）
- 只记录用户明确确认的阶段性成果，不记录讨论过程或未验证的想法
- 记录格式：时间 + 操作/成果 + 状态/备份位置
- 跨窗口对话时，先读取最近 3 天的工作记录了解上下文

## 规则优先级

- 用户当前明确指令 > 本文件（AGENTS.md） > SOURCE_OF_TRUTH.md
- 规则之间发生冲突时，询问用户澄清，不静默选择其中一条
