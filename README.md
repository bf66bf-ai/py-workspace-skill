# py-workspace - 工作区管理系统

为服务类创业者设计的 Claude Code 工作区管理系统。**新手友好，全程引导。**

作者：[pinyin](https://github.com/pinyin)

## 一行安装

```bash
cd ~/.claude/skills && git clone https://github.com/pinyin/py-workspace-skill.git py-workspace
```

**任何 Agent 窗口都可以使用。** 安装后在项目目录输入 `/py-workspace init` 即可开始。

## 为什么需要这个 skill？

如果你是咨询顾问、培训师、设计师或内容创作者，可能遇到过：

- ❌ 客户文档、课程资料、营销素材散落各处
- ❌ AI 助手不知道你的资料在哪，每次都要重新解释
- ❌ 新开一个窗口，之前的工作进展又要重新说一遍
- ❌ 文件到处复制，最后不知道哪个是最新版

**py-workspace 帮你解决这些问题。**

## 特色功能

### 🎯 新手友好

**首次使用自动启动引导模式**，每完成一步就告诉你下一步该做什么：

```

📍 你现在在：步骤 1/3 - 工作区已初始化
```

不需要看文档，跟着提示走就行。

### 🌍 全局可用

**在任何 Agent 窗口都能调用**，不限于特定项目或账号。

### ✨ 其他核心功能

- **智能分类**：识别你的分类习惯，自动归档文件
- **自动索引**：生成导航文件，AI 知道资料在哪
- **工作记录**：按日期记录产出，跨窗口续接
- **安全备份**：独立的交付物备份区
- **🚀 工作区自我进化**：累计 30 条工作记录后，Agent 主动分析你的工作模式，发现重复做的工作，建议生成对应的自动化 skill

- ✅ **一键初始化**：自动创建导航、规则、工作记录和文件交接区

- ✅ **移动而非复制**：避免版本混乱，保持唯一来源

## 核心概念

### 三层管理体系

1. **导航层**（SOURCE_OF_TRUTH.md）
   - 告诉 Agent 文件在哪里
   - 快速查找表
   - 目录职责说明

2. **规则层**（AGENTS.md）
   - 告诉 Agent 如何读取和使用文件
   - 读取优先级
   - 版本冲突处理
   - 引用确认规则

3. **工作层**（工作记录/）
   - 记录每日对话产出
   - 阶段性成果追踪
   - 跨窗口上下文续接
   - **自我进化的数据来源**：工作记录是最强真源，记录用户真实做了什么

### 文件交接机制

- **文件上传区**：临时入口，处理后文件被移走
- **文件下载区**：安全备份，可随时删除不影响主工作区

### 🚀 工作区自我进化机制

**这是一个惊喜功能**——工作区会主动学习你的工作模式。

#### 工作原理
1. **观察**：累计 30 条工作记录后，Agent 主动分析
2. **发现**：识别重复 3 次以上的固定模式
3. **建议**：生成可复用的 skill 建议表格
4. **确认**：先沟通后落盘，用户确认才创建

#### 可能发现的模式
- 新客户接入流程（每次都问预算、时间、范围）
- 月度数据复盘（统计收入、客户数、增长率）
- 课程项目创建（大纲 → 逐字稿 → 反馈整理）
- 客户交付准备（确认版本 → 复制到下载区 → 记录）

#### 示例输出
```
💡 工作区进化提醒

我注意到你的工作记录已经累计了 35 条，分析了你过去的工作模式。

值得整理成一组自己的工作 Skill。我建议先定下 5 类，其中 3 类优先制作。
这一轮没有创建或改文件。

| 候选 Skill | 工作记录中反复出现的操作 | 应固定的流程与完成标准 |
|-----------|------------------------|---------------------|
| ① 新客户接入 | 《张三-商业诊断》《李四-课程定制》等 5 次 | 询问预算/时间/范围 → 生成需求文档... |
| ② 月度数据复盘 | 《8月复盘》《9月复盘》等 2 次 | 扫描客户记录 → 统计收入、客户数... |

这些建议靠谱吗？如果觉得方向对，我可以生成详细的 skill 草稿。
```

**为什么这是惊喜？**
- ✨ 主动触发，不需要你记得
- ✨ 基于真实工作记录，不是猜测
- ✨ 先建议后执行，节省 token
- ✨ 发现你忽略的重复模式

## 技术细节

### 内容识别原理

Agent 通过以下方式识别文件：

1. **用户预分类优先**：保留用户的文件夹命名习惯
2. **文件名关键词**：识别"合同"、"课程"、"文案"等
3. **文件内容分析**：读取文本内容判断类型
4. **协商确认**：不确定时与用户确认

### 移动操作安全性

- 使用系统 `mv` 命令
- 移动前检查同名冲突
- 所有操作记录到工作日志
- 不在上传区保留副本（避免版本混乱）

### 自我进化分析原理

**数据来源**：工作记录 = 最强真源

不看文件结构、不看文件名，看用户实际做了什么：

#### 分析步骤
1. **快速扫描**：读取所有工作记录的标题和日期（不全文读取）
2. **关键词聚类**：按关键词对记录分组（例："新客户"、"接入" → "新客户接入"类）
3. **筛选重复**：找出重复 3 次以上的任务类型
4. **抽样验证**：每类只读 2-3 条完整记录，验证固定模式
5. **生成建议**：创建三列表格（候选 skill | 证据 | 流程标准）

**读取效率**：
- 总共只读 10-15 条完整记录
- 不是把所有记录全文读完
- 抽样验证，找典型案例

**触发条件**：
- 工作记录累计达到 30 条
- 后续每增加 30 条（60, 90, 120...）
- 最小间隔：至少新增 20 条

**输出原则**：
- ✅ 先建议，不自动创建
- ✅ 说清楚 Agent 做什么、不做什么
- ✅ 必须有实际工作记录支撑
- ✅ 用户确认后才生成 skill 文件

## 常见问题

### Q: 和个人商业诊断 skill 的关系？

A: 个人商业诊断是独立的 skill，专注于商业模式分析。Workspace Manager 只负责文件组织和工作流管理。两者可以配合使用，但互不依赖。

### Q: 必须按固定分类吗？

A: 不需要。Agent 会根据你放入上传区的实际内容，动态创建符合你业务的分类。

### Q: 支持多个项目吗？

A: 支持。你可以为每个客户或项目创建独立的子文件夹，Agent 会在索引中分别列出。

### Q: 可以修改规则吗？

A: 完全可以。AGENTS.md 是纯文本文件，你可以随时编辑。修改后 Agent 会在下次读取时应用新规则。

### Q: 误删了文件怎么办？

A: 
- 主工作区的文件：使用 Git 恢复或系统回收站
- 文件下载区的文件：这是备份，主工作区不受影响

### Q: 支持自动备份吗？

A: 目前不支持。建议将工作区文件夹同步到云盘（Dropbox、iCloud、坚果云）或使用 Git 版本管理。
